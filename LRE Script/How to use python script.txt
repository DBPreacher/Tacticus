----
Preparing for Python: 

1. Make sure Python is installed
Open a terminal (Terminal on Mac, or PowerShell/Command Prompt on Windows) and type:
python3 --version
If you get a version number (3.x), you're set. If not, install Python from python.org — grab the latest 3.x release, and on Windows check the box that says "Add Python to PATH" during install.

2. Install the one dependency
The script needs PyYAML to read the .yaml event files:
pip install pyyaml
(On some systems it's pip3 install pyyaml instead of pip.)
