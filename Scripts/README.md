# Scripts

Video scripts for DB Preacher Plays. The point of this folder is to learn
the channel's voice, so future scripts sound like the owner, not like an
AI.

| Folder / file | What goes in it |
|---|---|
| `Examples/` | Finished scripts from past videos: the **owner's own writing**, as used. These are the voice reference. Never edit them |
| `Transcripts/` | Optional: what was actually said on camera (e.g. YouTube auto-captions). Worth more than a script where the owner ad-libs |
| `Drafts/` | Claude's drafts, plus the owner's edited versions |
| `VOICE.md` | The style guide, written from `Examples/` and `Transcripts/` and corrected by the owner. Created once the examples are in |

**Names:** `YYYY-MM Type - Title`, e.g. `2026-08 Plan Now - LE15 Lysander.md`.
The type is Plan Now, Patch Notes, Does X Do Anything?, and so on. Plain
text (`.md` / `.txt`) is easiest; `.docx` works too.

**Drafts:** save the owner's edited version next to Claude's draft (e.g.
`... - draft.md` and `... - final.md`). The differences between the two are
how `VOICE.md` gets better.
